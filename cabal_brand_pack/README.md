# Cabal Final Brand Package — v2A Optical Stronger

Finalny pakiet brandingu Cabal oparty na kierunku **Secure Minimal**.

## Finalna decyzja

Wybrany wariant:

- wordmark: `v2A clean bold`, wyśrodkowany,
- ikona: `v2A balanced fill`,
- poziomy lockup: `optical_center_stronger`, czyli mocniejsza korekta optyczna,
- tło domyślne: `#0B0D12`.

## Mocniejsza korekta poziomego lockupu

Poziomy lockup używa następujących ustawień:

- artboard: `2400 × 720`,
- przesunięcie kompozycji: `-36 px`,
- rozmiar ikony: `375`,
- odstęp ikona–wordmark: `88`.

Rekomendowane pliki:

```text
svg/cabal_lockup_horizontal_final_optical_stronger_white.svg
svg/cabal_lockup_horizontal_final_optical_stronger_black.svg
svg/cabal_lockup_horizontal_final_optical_stronger_dark.svg
```
